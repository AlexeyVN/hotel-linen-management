# Участие в разработке

Проект распространяется по Apache License 2.0; отправляя изменения, вы соглашаетесь с условиями лицензии. Автор идеи — Vlasevskii Aleksei Nikolaevich.

## Перед изменениями

1. Прочитайте [README](README.md), [CONFIGURATION](docs/CONFIGURATION.md) и ТЗ ([v3.2](docs/hotel-linen-TZ-v3.2.md)).
2. Не коммитьте `.env`, `*.db`, `storage/`, `backups/`, `node_modules/`.
3. Для изменений схемы — миграция Prisma + проверка `migrate deploy` на пустой БД.

## Локальная проверка

```bash
cd app
npm ci
npm test
npm run build
```

Для UI-проверок нужен Chromium: `npx playwright install chromium`; скрипты — `app/scripts/ui-*.mjs`, запускаются против `https://hotel` или `http://127.0.0.1:3000` (см. шапку скрипта).

## Pull request

- Один логический change set; опишите проблему, решение, риски и откат.
- Приложите вывод тестов/build и ручную проверку.
- Обновите README/docs/CHANGELOG, если меняется поведение, настройка или деплой.
- Не добавляйте секреты и реальные данные клиентов.

## Навигация и ссылки

- При добавлении страницы, функции или интеграции проверяйте все необходимые точки входа и ссылки.
- Новые ссылки и пункты меню добавляйте только после диалога с пользователем и явного утверждения изменений/добавлений.
- Не оставляйте доступные страницы без навигационной точки входа.

## Стиль

- TypeScript strict, существующие паттерны tRPC/Prisma/React.
- Права проверяются на сервере; UI-скрытие — только дополнение.
- Русские тексты интерфейса; даты/деньги — через существующие форматтеры.
- Не смешивайте рефакторинг и функциональные изменения без необходимости.
