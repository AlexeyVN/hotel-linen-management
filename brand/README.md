## Использование

- Не растягивать, не менять цвета, не добавлять тень.
- На светлом фоне — цветной знак; на тёмном — знак с белым парусом.
- В приложении используется круглый знак, название выводится рядом/под ним.
- В Excel — знак + название отеля в шапке.
- В README — горизонтальный lockup.

Название в приложении: **«Белая пристань»**, `branding.hotelName`; акцентный цвет — `#0E2A47`.
