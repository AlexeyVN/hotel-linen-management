Дата: 2026-11-05. Статус: **реализовано и выложено на `https://hotel`**.
Утверждено: карточка с зонами, сворачиваемый пароль, outline-кнопка с карандашом, сетка формы, H1 без изменений.

## 2. Предлагаемая структура

### Вариант A — карточка пользователя с зонами (рекомендуется)

```
┌──────────────────────────────────────────────────────────────┐
│ [A]  Администратор системы                 [✎ Изменить ФИО/логин] │
│      admin · Администратор · [Активен]                        │
├──────────────────────────────────────────────────────────────┤
│ Роль: [Администратор ▼]        [Деактивировать]               │
│                                                              │
│ [Сменить пароль]  ← раскрывает блок (или всегда открыт)       │
│   Новый пароль: [__________]  [Сбросить]                      │
│   Не менее 8 символов                                        │
├──────────────────────────────────────────────────────────────┤
│ Назначенные номера                                           │
│ [101] [102] [103] [104] [201] ...        [Сохранить номера]   │
└──────────────────────────────────────────────────────────────┘
```

- Идентичность и главное действие — в шапке карточки; «Изменить» — заметная outline-кнопка с иконкой карандаша, высота 40 px.
- Роль и статус — отдельная строка с подписями; все контролы `h-10`.
- Пароль — отдельная зона «Безопасность», не в одной строке с ролью; кнопка «Сбросить» выровнена по нижнему краю поля, есть helper.
- Номера горничной — сетка `2 / 3 / 5` колонок, кнопка сохранения справа.
- Бейдж «Активен / Деактивирован».

### Вариант B — минимальная правка

- Вынести пароль в отдельную строку под ролью.
- Все `select`/`input`/`button` — `h-10`; `items-end`.
- «Изменить» — outline-кнопка с иконкой.
- Сетку и форму создания не трогать.

Быстро, но форма создания и мобильная раскладка останутся слабыми.

### Вариант C — таблица + модальное окно

Список компактный, действия в строке, редактирование/пароль — в модалке. Меньше визуального шума, но больше кликов и сложнее для мобильного.

**Рекомендация: A.** Карточки уже используются на странице; зонирование убирает смешение задач и даёт явную иерархию.

## 3. Детали варианта A

### 3.1 Шапка пользователя

- Слева: круг с инициалами, ФИО (16 px semibold), логин + роль, бейдж статуса.
- Справа: `<Button variant="outline">` с иконкой карандаша «Изменить ФИО / логин»; на мобильном — на всю ширину.
- В режиме редактирования: два поля (`ФИО`, `Логин`) в сетке, ниже — `Сохранить` (primary) и `Отмена` (ghost/outline); ошибка — под полями.

### 3.2 Роль и статус

- Подпись «Роль», селект `h-10`, ширина 200–240 px.
- Кнопка «Деактивировать/Активировать» — рядом, `h-10`, outline; для деактивации — `text-destructive` (не заливка, чтобы не пугать).
- Подпись статуса — бейдж, не мелкий текст.

### 3.3 Пароль

- Отдельный блок с заголовком «Сменить пароль».
- Варианты:
  - всегда открыт: поле + кнопка в сетке `minmax(0,1fr) auto`, helper «Не менее 8 символов»;
  - свёрнут: кнопка «Сменить пароль», по клику — поле и кнопка (чище, но +1 клик).
- Кнопка «Сбросить» disabled до 8 символов; причина disabled — helper.
- После успеха — локальное сообщение в блоке.

### 3.4 Номера (только MAID)

- Заголовок, сетка чекбоксов, кнопка «Сохранить номера» — отдельно справа/снизу; мобильная сетка 2 колонки.

### 3.5 Форма создания

- Сетка `md:grid-cols-2 xl:grid-cols-4`, поля с подписями, кнопка «Создать» — отдельная строка/правый нижний угол.
- Подсказки: логин `[a-z0-9._-]`, пароль ≥ 8 символов.
- Ошибки — рядом с формой.

### 3.6 Общие правила

- Все контролы `h-10`, одинаковый радиус/шрифт.
- Сетка: `gap-3`/`gap-4`, на мобильном — одна колонка, кнопки на всю ширину.
- Заголовки зон 12–13 px uppercase/muted; основной текст 14–16 px.
- Деструктивные действия визуально отличаются, но не являются primary.
- Фокус-ринг виден, `aria-label` у иконочных кнопок, label связан с input.
- 390 px: без горизонтального скролла, кнопки не меньше 40 px.

## 4. Критерии приёмки

1. В обычном режиме верх/низ пароля, селекта и кнопок совпадают (±1 px); все высоты 40 px.
2. «Изменить ФИО / логин» — заметная outline-кнопка с иконкой, не ниже 40 px; видна без наведения.
3. Пароль не находится в одной визуальной строке с ролью; есть заголовок и helper.
4. Форма создания выровнена сеткой, кнопка не «прилипает» к полям.
5. Редактирование: поля, Save/Cancel и ошибки локальны, остальные зоны не прыгают.
6. Мобильный 390 px: без переполнения, все кнопки доступны, пароль/роль не смещены.
7. Номера горничной — сетка, сохранение очевидно.
8. Клавиатурная навигация и фокус работают; `aria` корректны.
9. Тесты/build зелёные; Playwright-скриншоты до/после.

- Карточка пользователя: шапка с инициалами, ФИО, логин/роль/статус-бейдж, outline-кнопка «Изменить ФИО / логин» с карандашом (40 px).

- Номера горничной — сетка 2/3/5, кнопка сохранения отдельно.
- Проверено Playwright `users-layout` + `ui-nav-users`: edit/role 40 px, outline; пароль отдельно и выровнен; reset disabled; мобильный 390 без переполнения; 86 тестов; build.
