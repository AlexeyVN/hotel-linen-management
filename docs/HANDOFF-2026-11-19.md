## 6. Следующие шаги — по порядку

### Gate 1 — no-op PATCH

1. Взять один unit `LND` с `condition=Clean`.
2. Отправить JSON Patch с тем же `Clean`.
3. Проверить ответ и что состояние не изменилось.
4. Зафиксировать точный path/format.
5. Остановиться и согласовать Stage 1/2.

### Stage 1 — языки и устройства

1. Добавить `fr`.
2. `en` — initial default для admin/maids.
3. `User.locale` + личный выбор.
4. Резолвер: `user.locale > NEXT_LOCALE > installation default > env > en`.
5. `html lang`, Excel, даты, отчёты.
6. 12 role/locale тестов.
7. Android 9 / iPad 7 проверка.
8. Performance fixes: low-stock pagination, WAL, `Operation(documentDate)`, Excel concurrency.

### Stage 2 — Apaleo MVP

- settings `/admin/settings/integrations/apaleo`;
- enable/disable; property/client ID; секрет только env/файл;
- token cache/refresh;
- pull units → local rooms;
- push `status.condition`;
- mapping:
  - CLEAN → `Clean`;
  - DIRTY → `Dirty`;
  - INSPECTED → `CleanToBeInspected`;
  - OUT_OF_ORDER — не писать в v1;
- polling 5–15 минут;
- outbox/backoff/429;
- UI last sync/pending;
- no reservations/rates/folios;
- no public API key.

### Stage 3 — приёмка

- 6 языков;
- Android 9 / iPad 7;
- Apaleo read/push/read-back;
- offline queue;
- 100-room performance;
- backup/restore;
- archive.
